# **App Name**: IhsanMUN Interactive

## Core Features:

- Home Page Cinematic Intro: Animated hero section with text reveal on scroll, introducing Ihsan Schools MUN with interactive call-to-action buttons.
- About Us Scroll Storytelling: Scroll-driven narrative explaining Model United Nations and Ihsan Schools MUN’s mission with animated icons and timeline.
- Committee Card Animations: Animated cards displaying committee information with parallax or depth-based motion.
- Registration Form with Animated Feedback: A registration page using a Google Form with clear pathways for delegates, chairs, and staff, including input focus animations and success state.
- Secretariat Entrance Animations: Team member introductions with staggered entrance animations.
- Contact Form with Animated Transitions: Contact page featuring animated contact form with smooth transitions.
- Firestore Integration for Dynamic Content: Use Firestore to dynamically manage and update committee information, country allocations, and resource documents.

## Style Guidelines:

- Background color: White (#FFFFFF) for a clean and modern look.
- Accent color 1: Orange (#F26522) for call-to-action buttons, highlights, and emphasis.
- Accent color 2: Purple (#862B90) for headings, navigation accents, and dividers.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern and neutral look; suitable for both headlines and body text.
- Custom icons for committees, resources, and team roles to enhance visual storytelling.
- Clean and minimal layout with generous whitespace to create a premium, immersive feel.
- Smooth scroll-linked animations to guide users through the narrative, including staggered text reveals, image fades, and parallax effects.
